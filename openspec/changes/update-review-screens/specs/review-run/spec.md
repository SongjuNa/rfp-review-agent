## ADDED Requirements

### Requirement: 판정 목록 거르기와 판정 순서
시스템은 판정 목록을 주 유형, 검색어(항목 이름·영문 항목명·원문 문장), 확정 안 한 것만으로 거르고, 요청하면 판정 순서(일탈 후보 → 질의 후보 → 확인 필요 → 작성 필요 → 준수, 같은 판정 안에서는 판정 번호 순)로 정렬해야 한다(SHALL). 걸러진 전체 개수는 지금처럼 함께 알려 준다. 판정 줄에는 주 유형 코드와 이름을 넣는다(SHALL).

#### Scenario: 확정 안 한 일탈 후보만
- **WHEN** 일탈 후보 4건 중 1건을 확정한 실행에서 일탈 후보이면서 확정 안 한 판정만 요청하면
- **THEN** 3건이 오고 전체 개수도 3이다

#### Scenario: 판정 순서로 받기
- **WHEN** 판정 순서로 목록을 요청하면
- **THEN** 일탈 후보가 모두 질의 후보보다 앞에 오고, 준수는 맨 뒤에 온다

#### Scenario: 검색어로 거르기
- **WHEN** 검색어 "busbar"로 요청하면
- **THEN** 영문 항목명에 busbar가 들어간 판정만 온다

### Requirement: 판정 칩 건수
시스템은 실행의 현재 판정을 판정 값마다 센 건수, 확정 안 한 판정 수, 그중 준수 수를 한 번에 알려 줘야 한다(SHALL). 반려한 판정은 세지 않는다.

#### Scenario: 칩 건수
- **WHEN** 판정 칩 건수를 요청하면
- **THEN** 판정 값마다의 건수 합이 전체 판정 수와 같고, 확정 안 한 수는 확정·수정한 판정을 뺀 수다
