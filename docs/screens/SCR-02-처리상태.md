# 화면 명세: SCR-02 처리 상태

- 연결 요구사항: FR-01~06·07~15 처리 흐름, `review-workspace` 처리 상태 화면
- 기준 목업: `Spec2Win_목업_v4.57.html#Loading` (`.ldo` 로고 + 진행 막대 + 문장)
- 구현 방식: 실제 (`update-review-screens` 묶음 11)
- 사용 API: `GET /runs/{id}` (`stage`, `step`, `documents`, `requirements`). 처리 중이면 2초마다 다시 묻는다
- 예정 API: 없음

## 화면 구성

| 영역 | 보이는 항목 | API 칸 | 비고 |
|---|---|---|---|
| 머리글 | 검토 번호, "처리 중", 제목, 문서 수·담당 | 검토 정보 | SCR-08 머리글 그대로 |
| 로고 | Spec2Win 색 로고 | — | |
| 진행 막대(`role=progressbar`, 이름 "RFP 분석") | 막대 + 백분율 | `step` | 단계 순서 n / 11 × 100, 99에서 멈춤 |
| 문장(`.ldtx`, `aria-live`) | 단계 문장 · 문서 n개 · 요구사항 n개 | `step`, `documents`, `requirements` | 단계: 처리를 시작하는 중, 문서 읽는 중, 원본·정정본 찾는 중, 위험 조건 찾는 중, 제품과 비교해 판정하는 중, 공학 규칙 검산 중, 보증값 후보 만드는 중, 손실 환산 중, 일탈·질의 목록 만드는 중, 제안 포인트 만드는 중, 담당자에게 나누는 중 |

처리가 끝나면(담당자 확인 단계) 같은 주소에서 탭과 요약 칸이 있는 검토 상세로 바뀐다. 처리 실패는 SCR-11.

## 수용 기준 (Given / When / Then)

- **Given** 위험 조건 찾기 단계인 검토, **When** 검토 상세를 열면, **Then** 진행 막대 값이 0과 100 사이, "위험 조건 찾는 중", 끝나면 판정 탭. (처리 중인 검토)
