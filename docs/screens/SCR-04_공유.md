# SCR-04 사업 현황: 목업과 다르게 만든 것 (공유)

| # | 목업 | 앱 | 이유 |
|---|---|---|---|
| 1 | 실제 지명·고객사 이름 | "예시 사업장 A", "예시 고객사 A" (입찰 이력과 같은 글자) | 예시 데이터에 고객사·지명을 넣지 않는 규칙 |
| 2 | 영업·담당자 사람 이름 | 역할 이름 (영업 담당 A, 기술 검토 엔지니어 A …) | 사람 이름을 넣지 않는 규칙 |
| 3 | 고객 입찰 번호에 고객사 약자 (예: ITB-AJP-2026-044) | 숫자만 남김 (ITB-2026-044) | 약자로 고객사를 알 수 있다 |
| 4 | 맨 위에 띠 없음 | 예시 띠 | 사업 단위 API가 없다 |
| 5 | "내 사업"은 로그인한 사람 기준 | 예시 데이터의 고정 표시(`mine`) | 머리글에서 고른 사용자와 연결하지 않는다 |
