# SCR-08-7 지난 RFP 비교 탭: 목업과 다르게 만든 것 (공유)

| # | 목업 | 앱 | 이유 |
|---|---|---|---|
| 1 | 실제 기능 | 예시 화면(예시 띠, 저장 안 함) | 같은 고객의 지난 검토를 찾고 요구를 짝짓는 API가 없다 |
| 2 | "같은 고객 Vietnam Power Transmission", 사업 "Quang Ninh · …" | "같은 고객", "예시 변전소 A · …" | 예시에 실제 고객사·지명을 쓰지 않는다 |
| 3 | 줄을 누르면 이번 판정의 원문(판정 상세 창)을 엶 | 누를 수 없음, 아래 문장에서 "줄을 누르면 …" 뺌 | 예시 판정은 실제 판정 표에 없다 |
| 4 | 입찰 번호 링크는 입찰 상세로 | 입찰 이력 화면으로 | 입찰 상세 화면이 아직 없다 (예시 화면 단계) |
