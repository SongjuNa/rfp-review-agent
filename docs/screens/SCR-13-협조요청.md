# 화면 명세: SCR-13 협조 요청 현황

- 연결 요구사항: FR-11(유형별 담당자 전달), `role-assignment`, `review-workspace` 협조 요청 현황 화면
- 기준 목업: `Spec2Win_목업_v4.57.html#Todo`
- 구현 방식: 실제 + 예시 창 (`update-review-screens` 묶음 13). 화면 CSS는 목업 Todo CSS 그대로(`frontend/src/mockup/Todo.css`)
- 사용 API: `GET /assignments?role=COST|QUALITY|SALES`(모든 검토의 그 부서 요청, 검토 번호·파일 이름·보낸 사람 포함), `PUT /assignments/{id}`(받는 담당자의 상태 바꾸기)
- 예정 API: 재요청, 직접 요청 만들기, 회신 글, 내보내기(Excel)

## 화면 구성

| 영역 | 보이는 항목 | API 칸 | 비고 |
|---|---|---|---|
| 수신 부서 탭(`.pgtabs`) | 견적 담당 · 품질 담당 · 영업 담당 · 미분류 | `role` | 처음 탭: 견적·품질·영업 사용자는 자기 부서, 그 밖에는 견적 담당. 미분류는 보낼 곳이 정해지지 않은 요청이 없어 늘 빈 목록 |
| 제목(`.ttl`) | 탭 이름, 내보내기 | — | 내보내기 잠김 |
| 요약 줄(`.sumline`) | 미확인 · 24시간 넘게 미확인 · 확인 | `status`, `sent_at` | 화면을 연 시각 기준 |
| 요청 표(`.tbl`) | 상태, 요구사항(묶음·제안 포인트 꼬리표, 문장, 팀 가정, 유형·묶음 설명, 검토 번호 연결, 원문 위치), 수신자, 요청 일시, 재요청 | `text`, `type_name`, `repeat_count`, `point_kind`, `is_assumed`, `review_no`, `locations`, `file_name`, `assignee`, `sent_at` | 확인한 줄은 흐리게. 10·20·50개씩 쪽 나눔. 재요청 잠김 |
| 요청 상세 창(`.pmw.cw`) | 상태, 문장, 부서 · 수신자 / 요청 내용, 팀 가정 안내, RFP 원문(위치 + 문장), 회신 / 관련 검토, 수신 부서, 수신자, 보낸 사람, 회신 기한 / 진행 | 위와 같음, `updated_at`, `engineer_name` | 회신 기한 = 보낸 날 + 3일(목업 규칙), 지나면 빨강 |
| 상세 창 아래 단추 | Esc로 닫기, 검토 상세 열기, (받는 역할 사용자) 확인함 → 처리 끝, (그 밖) 재요청 잠김 | `PUT /assignments/{id}` | 확인함 = 하는 중, 처리 끝 = 끝 |
| 요청하기 창(`.nwd`) | 예시 띠, 관련 검토, 원문 위치, 요구사항, 수신 부서·수신자, 요청 내용, 회신 기한, 원문 발췌 함께 보냄 | — | 예시. 빈칸이면 목업과 같은 오류 문구, 보내면 "예시 화면이라 보내지 않았습니다" 알림만 |

## 상태 바꾸기

| 할 일 상태 | 화면 상태 | 진행 |
|---|---|---|
| 할 일, 보낸 지 24시간 이하 | 미확인(파랑) | 요청 보냄 → 회신 대기 |
| 할 일, 24시간 넘음 | 24시간 넘게 미확인(주황) | 요청 보냄 → 24시간 넘게 미확인(재요청 필요) → 회신 대기 |
| 하는 중 | 확인(회색, 줄 흐림) | 요청 보냄 → 확인 → 회신 대기 |
| 끝 | 확인(회색, 줄 흐림) | 요청 보냄 → 확인 → 처리 끝 |

## 수용 기준 (Given / When / Then)

- **Given** 품질 담당에게 간 형식시험 요청, **When** 엔지니어가 품질 담당 탭을 고르면, **Then** "미확인" 줄과 검토 번호, 파일 이름이 든 위치, 요약 수. (수신 부서별 요청 현황)
- **Given** 보낸 지 24시간이 넘은 할 일, **When** 화면을 열면, **Then** "24시간 넘게 미확인", 상세 진행에 "재요청 필요". (24시간 넘게 미확인)
- **Given** 품질 담당 사용자, **When** 상세 창에서 "확인함"을 누르면, **Then** 줄이 "확인"으로 흐려지고 "처리 끝" 단추가 보인다. (받는 담당자의 확인)
- **Given** 요청하기 창, **When** 적고 보내면, **Then** 예시 알림만, 요청 수 그대로. (요청하기 예시)
