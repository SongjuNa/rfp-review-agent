## 화면 구성

| 영역 | 보이는 항목 | 데이터 칸 | 비고 |
|---|---|---|---|
| 예시 띠 | 예시 화면 · 실제 데이터와 연결되지 않음 | — | |
| 제목(`.ttl`) | 사업 현황, RFP 등록 | — | RFP 등록은 실제 검토 등록 화면으로 |
| 요약(`.sh-sum`) | 진행 중 사업, 3일 내 제출 마감, 마감 지남, 등록 전 범위 | `done`, `n`, `ranges[].key` | 범위(내 사업·팀 전체)만 따른다 |
| 머리 줄 | 사업 n, 내 사업 · 팀 전체 | `mine` | |

## 수용 기준 (Given / When / Then)

- **Given** 왼쪽 메뉴, **When** 사업 현황을 열면, **Then** 예시 띠와 내 사업 10건이 마감 가까운 순으로 보인다. (예시 띠)
- **Given** 사업 현황, **When** 상태를 "전체"로 바꾸고 검색을 누른 뒤 다른 화면에 갔다 오면, **Then** 상태가 "진행 중"으로 돌아와 있다. (저장하지 않음)
