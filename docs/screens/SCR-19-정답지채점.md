# 화면 명세: SCR-19 정답지·채점

- 연결 요구사항: 기획서 K1~K12 지표 (정답지·채점기는 남은 작업)
- 기준 목업: `Spec2Win_목업_v4.57.html#Eval`
- 구현 방식: 예시 화면 (`add-example-screens`). 데이터는 `frontend/src/examples/SCR-19.ts`, 화면은 `frontend/src/views/examples/Eval.tsx`, CSS는 목업 Eval CSS 그대로
- 사용 API: 없음
- 예정 API: 정답지 목록, 채점 실행, 지표 결과, 개선 기록

## 화면 구성

| 영역 | 보이는 항목 | 데이터 칸 | 비고 |
|---|---|---|---|
| 예시 띠 | 예시 화면 · 실제 데이터와 연결되지 않음 | — | |
| 제목 | 정답지·채점, 설명, 지금 채점하기 | — | 누르면 1.6초 뒤 바뀐 지표가 0.4 오른 모습(목업과 같음). 화면 안에서만 |
| 안내(`.sh-note`) | 사람 판정은 힌트로만, 자동 확정 없음 | — | |
| 요약(`.sh-sum`) | 정답지 줄 수, 검토 수, 마지막 채점, 목표 달성 n / 12, 지난번보다 좋아짐 | 정답지 넣기 체크에 따라 바뀜 | |
| 채점 결과 탭 | 지표, 무엇을 재나, 지난, 이번, 변화(▲▼), 목표(달성 초록·미달 주황) | `EXAMPLE_METRICS` | 10개씩 쪽 나눔 |
| 정답지 탭 | 넣기 체크, 검토, 확정한 사람, 확정일, 판정 줄, 결재 후 후보 안내 | `EXAMPLE_GROUND_TRUTH` | 체크는 화면 안에서만 |
| 개선 기록 탭 | 날짜, 고친 곳, 무엇을 고쳤나, 점수 변화, 한 사람 | `EXAMPLE_SCORE_LOG` | |

## 수용 기준 (Given / When / Then)

- **Given** 왼쪽 메뉴, **When** 정답지·채점을 열면, **Then** 예시 띠와 지표 12개(10개씩), 목표 달성 9 / 12가 보인다. (예시 띠)
- **Given** 정답지 탭에서 검토 하나를 빼면, **When** 다른 화면에 갔다 오면, **Then** 처음처럼 5건이 들어 있다. (저장하지 않음)
