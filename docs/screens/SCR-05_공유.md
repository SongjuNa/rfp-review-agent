# SCR-05 사업 상세: 목업과 다르게 만든 것 (공유)

| # | 목업 | 앱 | 이유 |
|---|---|---|---|
| 1 | 실제 지명·고객사 이름 | "예시 사업장 A", "예시 고객사 A" | 예시 데이터에 고객사·지명을 넣지 않는 규칙 (SCR-04와 같은 글자) |
| 2 | 사내 담당자·메모의 사람 이름, 이름 첫 글자 아바타 | 역할 이름 (기술 검토 엔지니어 A, 설계 담당 B, 결재자 …), 역할 첫 글자 | 사람 이름을 넣지 않는 규칙 |
| 3 | 고객 입찰 번호에 고객사 약자 | 숫자만 | 약자로 고객사를 알 수 있다 |
| 4 | 맨 위에 띠 없음 | 예시 띠 | 사업 단위 API가 없다 |
| 5 | 범위 카드가 검토 상세·처리 실패·결재 대기 화면의 그 검토로 감 | 검토 목록으로 감 (협조 요청·검토 등록·입찰 상세는 그대로) | 예시 검토 번호는 실제 검토가 아니다 |
| 6 | 접속 상태·"나" 표시가 로그인한 사람 기준 | 예시 데이터 고정 (기술 검토 엔지니어 A가 "나") | 머리글에서 고른 사용자와 연결하지 않는다 |
