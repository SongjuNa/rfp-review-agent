# SCR-08-6 상업 조건 탭: 목업과 다르게 만든 것 (공유)

| # | 목업 | 앱 | 이유 |
|---|---|---|---|
| 1 | 실제 기능 | 예시 화면(예시 띠, 저장 안 함) | 상업 조항 추출은 차별화 아이디어 C1로 팀 결정 대기. 가격 계산은 범위 밖 |
| 2 | 담당 "견적 · 정우진 대리", 회신자 "정우진 대리" | "견적 담당", "영업 담당" | 예시에 사람 이름을 쓰지 않는다 |
| 3 | 통화 "USD 60 % 이상 · VND 허용" | "현지 통화 허용" | 예시에 특정 고객 나라를 드러내지 않는다 |
| 4 | 탭 이름 옆 미전달 수 8 | 숫자 없음 | 예시 데이터 수를 실제 할 일처럼 보이지 않게 한다 |
| 5 | 상신 전 확인의 "상업 조건 미전달 n건" 줄 | 넣지 않음 | 예시 데이터라 결재 판단에 섞지 않는다 |
| 6 | 상업 영향의 "판정 · …" 연결을 누르면 판정으로 이동 | 이동하지 않음(마우스를 올리면 이유) | 예시 판정은 실제 판정 표에 없다 |
| 7 | 전달하면 이력에 "상업 조건 전달" 줄 | 이력에 남기지 않음 | 예시 화면은 저장하지 않는다 |
