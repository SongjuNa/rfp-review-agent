# SCR-08-8 제출본 탭: 목업과 다르게 만든 것 (공유)

| # | 목업 | 앱 | 이유 |
|---|---|---|---|
| 1 | v1, v2 … 여러 판, "새 판 작성 시작" | v1 한 판 | 승인된 실행은 다시 열 수 없다(반려만 다시 확인). 새 판은 새 검토로 한다 |
| 2 | 승인 때 판정 사본(snap)을 저장하고 다음 판과 차이 수를 셈 | 사본 없음, 지금 판정 수 | 승인 뒤 판정이 바뀌지 않아 사본이 같은 값이다 |
| 3 | 빈 안내 "사내 전자결재에서 승인되면" | "결재자가 승인하면" | 결재는 이 시스템 안에서 한다. 사내 전자결재 연동은 범위 밖 |
| 4 | 첨부 "3개"(일탈 목록, 질의서, 데이터시트) | 인계 패키지에 들어가는 파일 수(일탈 목록·질의서 초안 중 있는 것, TBE 준수표, 데이터시트 표마다 1개) | 데이터시트는 고객 표마다 한 장이고, 영업에 넘기는 패키지와 같은 셈으로 보인다 (`add-submission-package`) |
| 5 | 결재자 "김태호 책임" | 사용자 이름 | 직급이 없다 |
| 6 | 인계 패키지 영역 없음 | 표 아래에 "인계 패키지 내려받기"·"영업에 넘기기"와 마지막으로 넘긴 기록 | 계획 문서(10-31) 3장 인계 패키지. 결과 파일을 하나씩 받아 메일에 붙이던 일을 줄인다 (`add-submission-package`) |
