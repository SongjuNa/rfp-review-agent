# 화면 명세: SCR-00 앱 틀

- 연결 요구사항: `review-workspace` (앱 틀과 화면 주소), 모든 화면의 바깥 틀
- 기준 목업: `Spec2Win_목업_v4.57.html#Main`의 왼쪽 메뉴·머리글 (모든 화면이 같은 틀)
- 구현 방식: 실제. 알림은 예시 (`SCR-00_공유.md`)
- 사용 API: `GET /api/users` (사용자 고르기), `GET /api/runs` (머리글 검색)
- 예정 API: 없음

## 2. 화면 주소

메뉴에 없는 화면 주소. 새 라우터 의존성 없이 `#` 뒤 주소를 쓴다(목업도 `#화면 키`로 화면을 연다).

| 주소 | 화면 | SCR |
|---|---|---|
| `#/reviews/:id` | 검토 상세 (탭은 화면 안에서 고름) | SCR-08 |
| `#/reviews/:id/tbe` | TBE 준수표 | SCR-09 |
| `#/reviews/:id/datasheet` | 데이터시트 | SCR-10 |
| `#/reviews/:id/fail` | 분석 실패 상세 | SCR-11 (예정) |
| `#/reviews/:id` (승인 대기일 때) | 결재 대기 상세 | SCR-12. 주소를 따로 두지 않고 승인 대기 검토를 열면 보인다 (`update-approval-flow` 결정) |
| `#/reviews/:id/loading` | 처리 상태 | SCR-02 (예정) |
| `#/projects/:id`, `#/bids/:id` | 사업·입찰 상세 (예시) | SCR-05, SCR-15 (예정) |
| `#/login` | 로그인 (예시) | SCR-01 (예정) |

- 모르는 주소는 홈으로 본다.
- 아직 만들지 않은 화면은 틀 안에 제목과 "아직 만들지 않았습니다" 안내만 보인다. 화면을 만들 때마다 지운다.
- 머리글 위치(`.crumb`)는 `홈 > 묶음 메뉴 > 화면`. 마지막 칸은 굵은 글자이고 나머지는 링크.

## 화면 구성

| 영역 | 보이는 항목 | API 칸 | 비고 |
|---|---|---|---|
| 왼쪽 메뉴 위 | Spec2Win 로고(흰 글자), "RFP 기술 검토 지원 시스템" | — | 로고를 누르면 홈 |
| 왼쪽 메뉴 | 1장 메뉴, 빛·점 무늬 효과 | — | 움직임 줄이기 설정이면 효과를 멈춤 (목업 CSS) |
| 머리글 왼쪽 | 메뉴 접기 단추, 위치 | — | 접은 상태는 브라우저에 기억 (`s2w.sbMini`) |
| 머리글 검색 | 입력 + "검색" 단추, 결과 겹창 | `RunListItem.run_id`, `files`, `stage`, `started_at` | 검토만 찾는다. 4건까지 보이고 누르면 검토 상세 |
| 머리글 오른쪽 | 도움말, 알림(읽지 않은 수), 사용자(글자 아바타·이름·역할·온라인 점) | `User.user_name`, `role` | 알림은 예시 |
| 사용자 겹창 | 사용자 목록, 지금 사용자 강조 | `GET /api/users` | 고른 사용자는 브라우저에 기억 (`s2w.user`) |

## 화면 상태

- 로딩 중: 사용자 목록이 오기 전에는 "사용자 없음"으로 보인다.
- 오류: 사용자 목록을 못 받아도 틀은 그대로 보인다. 각 화면이 자기 오류를 보인다.

## 수용 기준 (Given / When / Then)

- **Given** RFP 검토 화면, **When** 지식 관리 > 제품 관리를 누르면, **Then** 주소가 `#/products`가 되고 제품 관리 메뉴가 강조되며 위치에 "홈 > 제품 관리"가 보인다. (메뉴로 화면 이동)
- **Given** 아무 화면, **When** 주소 `#/todo`를 바로 열면, **Then** RFP 관리 묶음이 펼쳐지고 협조 요청이 강조된다. (메뉴로 화면 이동)
- **Given** 펼친 메뉴, **When** 메뉴 접기를 누르고 새로 고치면, **Then** 메뉴는 접힌 채로 보인다. (메뉴 접기)
- **Given** 엔지니어로 보는 중, **When** 사용자 겹창에서 기본 승인자를 고르면, **Then** 머리글에 "기본 승인자 · 승인자"가 보이고 새로 고쳐도 유지된다. (사용자 바꾸기)
- **Given** 알림 단추, **When** 누르면, **Then** "예시" 꼬리표가 붙은 알림이 보이고 모두 읽음으로 하면 읽지 않은 수가 0이 된다. (알림은 예시로 보인다)
