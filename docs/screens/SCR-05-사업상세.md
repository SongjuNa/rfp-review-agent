# 화면 명세: SCR-05 사업 상세

- 연결 요구사항: 없음 (사업 단위는 `add-review-info` Non-Goal)
- 기준 목업: `Spec2Win_목업_v4.57.html#Project`
- 구현 방식: 예시 화면 (`add-example-screens`). 데이터는 `frontend/src/examples/SCR-04.ts`, 화면은 `frontend/src/views/examples/Project.tsx`, CSS는 목업 Project CSS 그대로
- 주소: `#/projects/<사업 번호>`. 없는 번호면 목업처럼 첫 사업을 연다
- 사용 API: 없음

## 화면 구성

| 영역 | 보이는 항목 | 데이터 칸 | 비고 |
|---|---|---|---|
| 예시 띠 | 예시 화면 · 실제 데이터와 연결되지 않음 | — | |
| 머리(`.pd-top`, `.ttl`) | 사업 번호, 고객 입찰 번호, 진행 상태, 사업 이름, 사업 목록, 이 사업에 RFP 등록 | `id`, `tender`, `done`, `title` | RFP 등록은 실제 검토 등록 화면으로 |
| 사업 정보(`.pd-info`) | 사업명, 고객사 · 국가, 발주 방식, 제출 마감, 다음 일정, 내 역할 | `short`, `cust`, `cty`, `mode`, `dd`, `sched`, `role` | |
| 개요 탭 | 설비 범위 카드: Lot, 상태, 범위, 검토 번호, 담당, 메모, 다음 동작 | `ranges` | 카드는 실제 화면(검토 목록, 협조 요청, 검토 등록, 입찰 상세)으로 감 |
| 담당자 탭 | 사내 담당자(역할, 이름, 맡은 범위, 접속 상태, 협조 요청), 고객 측 창구, 개인 연락처 안내 | `team`, `client` | 접속 상태는 예시 |
| 일정 탭 | 날짜 · 일정 · 지남/D-n | `sched` | |
| 문서 탭 | 문서, 종류, 받은 날, 영향 범위 | `docs` | 파일 이름만 |
| 지난 이력 탭 | 같은 고객의 지난 입찰 (입찰 상세로) | `hist` | 이름은 입찰 이력 예시와 같다 |

## 수용 기준 (Given / When / Then)

- **Given** 사업 현황, **When** 사업 줄을 누르면, **Then** 예시 띠와 그 사업의 설비 범위 카드가 보인다. (예시 띠)
- **Given** 사업 상세, **When** 지난 이력 탭에서 입찰을 누르면, **Then** 같은 이름의 입찰 상세가 열린다.
- **Given** 담당자 탭을 연 뒤, **When** 다른 사업으로 갔다 오면, **Then** 개요 탭으로 돌아와 있다. (저장하지 않음)
