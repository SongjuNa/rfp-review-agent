## 1. 왜 했나

- 팀 평가 기준 AI-5 "테스트를 통한 개선 과정"에서, 모델 비교에 쓴 정답이 **Claude가 만든 것**(유형 정답지 100줄 "Claude 초안·사람 확인 0줄", 갈린 요구사항 문장 "Claude 판단")이라는 약점이 있었습니다. AI가 정한 정답으로 AI를 채점하면 근거가 되지 않습니다.
- 기획서 8-1의 원칙 "작성자와 검토자를 다른 사람으로"에 맞춰 사람 2명이 따로 확인했습니다.

## 2. 확인 ①: 이 문장이 요구사항인가 (18줄)

### 무엇을

- 실제 흐름에서 **두 모델의 판단이 갈린 요구사항 후보 문장 전부**: 파일 1(`1. Bidding Forms_Draft`) run 33(3.8 Flash) vs run 35(3.5 Flash-Lite) 17줄 + 파일 18(`262000 Electric Distribution`) run 30 vs run 36 1줄. 출처 `data/private/diag/diff_run33_run35.csv`, `diff_run30_run36.csv`.
- 질문: "계약하면 공급사(우리, LS)가 지켜야 하는 요구사항인가?" Y / N / ?(모르겠음).
- 시트에 준 판단 기준 (Claude가 작성):
  - (가) 계약 뒤에 우리가 장비·공사·가격·일정에서 이 문장대로 해야 하나 → Y
  - (나) 입찰서를 낼 때 "이 칸에 이렇게 적어라"는 작성 방법·서식 안내일 뿐이거나, 다른 사람(은행 등)의 말 → N
- 모델 답과 Claude 판단은 시트에 넣지 않았습니다. 대신 Claude가 쓴 **쉬운 우리말 풀이 칸**을 넣었습니다(사람 1이 영어가 어렵다고 해서). 풀이에는 "[입찰 자격 서식 안내]"처럼 그 문장이 어떤 서류의 일부인지 적었고, Y/N은 적지 않았습니다.
- 3.8 / Lite 칸의 Y는 시스템 분류 REQUIREMENT, N은 WRITING_RULE(작성 규칙)·설명·후보 아님입니다.

### 해석

- **두 사람 모두 "서식 작성 안내"(1·3·7·10·17·18번)를 요구사항(Y)으로 봤습니다.** 시스템은 이것을 요구사항에서 뺍니다. 3.8 Flash가 작성 규칙으로 거르고, 입찰 서식 처리기의 C1 규칙도 "표 밖 서식 작성 안내는 작성 규칙으로" 둡니다(기획서 5-1-1, `docs/개발_기록_C1C2.md`). 시트의 기준 (나)는 이런 줄을 N으로 안내했는데도 두 사람 모두 Y를 골랐습니다.
- 그래서 이 18줄의 차이는 **모델 실력보다 "요구사항" 정의의 차이**입니다. 시스템(그리고 Claude)의 정의는 "계약 뒤 의무"이고, 사람 2명의 직관은 "우리가 해야 하는 일 전부"였습니다.
- 나머지 8줄(6·8·11~16번)은 사람끼리도 갈렸습니다. 원래 애매한 문장입니다.
- **결론: 이 18줄은 모델 비교 근거로 쓰지 않습니다.** "AI가 정한 정답만 믿었으면 반대 결론을 발표할 뻔했고, 사람 확인으로 정의 차이를 찾았다"는 **개선 과정의 사례**로 씁니다.

## 4. 주의할 점 (판단할 때 반드시 고려)

1. **사람 2의 답이 다른 답과 완전히 같습니다.** ② 30줄이 Claude 초안과 30/30, ① 18줄이 3.5 Flash-Lite와 18/18 같습니다. 시트에는 두 답 모두 없었습니다. 혼자 판단해서 두 시트 모두 100 % 같기는 드물어서, **AI나 초안 파일을 참고했는지 확인이 필요합니다(2026-11-02 기준 미확인).** 참고했다면 사람 2는 "사람 확인"이 아니고, 두 사람 합의 숫자도 다시 내야 합니다. 그 경우 사람 1만의 결과(① 3.8 7 / Lite 10, ② 3.8 21 / Lite 17 / 3.1 14)도 결론 방향은 같습니다.
2. **우리말 풀이는 Claude가 썼습니다.** 사람 판단이 풀이의 말투에 영향을 받았을 수 있습니다. 특히 ①의 "[서식 안내]" 같은 꼬리표.
3. 확인한 사람은 전력 설비 입찰 실무자가 아닙니다. 실무자 기준은 다를 수 있습니다.
4. 표본이 작고(18줄, 30줄) 일부러 어려운 줄을 많이 넣었습니다.
5. ①의 3.8 / Lite는 실제 흐름 결과이고, ②의 모델 답은 스크립트로 100줄을 모두 AI에 직접 물은 결과입니다. 조건이 다릅니다.
