- **시연용 합성 RFP 위험 조항** (add-synthetic-risk-rfp): 팀이 실제 RFP 대신 합성 RFP로 시연하기로 해(11-02) 파일 23~26을 main으로 돌려 보니 일탈 후보(파일 25: 10)·협조 요청(파일 26: 3·3·3)은 의도대로였지만 위험 조건이 4개 모두 0이었다(합성 문서에 위험 표현·값 불일치 없음). 파일 26에 9장을 더한 파일 27을 만들어 위험 조건 4(포괄 2·범위 모호 1·값 불일치 1)가 나오게 했고, 합성 RFP가 "종류 모름"이던 것을 문서 종류 규칙 한 줄로 요구 사양서로 바꿨다. 테스트 DB는 고정 제품표를 써서 일탈 수가 달라(4) 이 테스트만 실제 제품표를 적재했다.
